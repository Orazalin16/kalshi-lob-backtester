## 3. Replay speed

Machine: x86_64, Intel(R) Xeon(R) Processor @ 2.10GHz; Python 3.13.16. Tape: 3,313,802 events (24 simulated hours).

| measurement | result |
|---|---|
| C++ book replay | 148.0 M events/s (6.8 ns/event) |
| C++ replay with the fill simulator attached, no orders resting | 53.7 M events/s |
| Python reference book replay | 2.68 M events/s |
| Speedup over the reference | 70x |
| Full strategy backtest of the tape (345,600 Python decision steps) | 1.8 s |
